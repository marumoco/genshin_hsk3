# HSK3級 完全制覇リーダー (原神風 PWA)

HSK3級の単語・例文を効率よく学習できるPWA（Progressive Web App）対応のWebリーダーです。

## 主な機能
- 📱 **PWA対応**: スマートフォンのホーム画面に追加してネイティブアプリ感覚でオフライン利用可能
- ⚔️ **原神風デザイン**: 美しく親しみやすいUI
- 🔊 **音声・ピンイン**: 各単語・例文の発音確認
- 🔍 **シーン別学習**: 全60景に分類された実戦的フレーズ集

## GitHub Pages での公開手順
1. リポジトリの **Settings** タブを開く
2. 左メニューの **Pages** を選択
3. **Build and deployment** の Source で **Deploy from a branch** を選択
4. Branch に **main** / **root** を指定して **Save** をクリック
5. 数分後に `https://marumoco.github.io/genshin_hsk3/` でアクセス可能になります。
